MxWave GLM-5.3 runtime bundle

The Python wrappers and exact scale/BF16 row codecs are MxWave code under the
repository's Apache-2.0 license. Their source origins are recorded in
source-provenance.json. No DeepInfer implementation is included.

The externally prepared native libraries contain adaptations of:

1. vllm-project/vllm, revision db9527a46873454610df6dbedf79a36d6bf1a7f6.
   License: Apache-2.0, supplied as vllm-Marlin-LICENSE.
   Libraries: libmxwave_moe_raw.so and libmxwave_moe_sparse.so.
   MxWave adds C ABI launch plumbing and lossless scale decoding/staging to the
   grouped Marlin MoE kernel. The source retains upstream notices. Exact inputs
   and changes are recorded in integrations/glm53_mxfp4/moe_sources.json,
   build_moe.py, and CONTRIBUTING.md in the MxWave source repository.
   https://github.com/vllm-project/vllm/tree/db9527a46873454610df6dbedf79a36d6bf1a7f6

2. xxyux/ZipServ, revision f69cea959005222bed64fc847bc3fcdcca32a904.
   License: Apache-2.0, supplied as ZipServ-LICENSE.
   Library: libmxwave_kda_zipserv.so (used here for the vocabulary head).
   MxWave adds a stream-aware C ABI bridge and safe tensor handling, removes an
   unused CUDA-13-incompatible include, and fixes layer-specific shared-memory
   sizing. The external source build retains upstream notices.
   https://github.com/xxyux/ZipServ/tree/f69cea959005222bed64fc847bc3fcdcca32a904

The upstream vLLM 0.32.0 Python installation is a separate dependency. This
package does not distribute a patched vLLM source tree. Its own runtime hooks
modify behavior only in explicitly opted-in processes.
